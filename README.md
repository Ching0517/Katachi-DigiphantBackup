# Katachi DigiPhant

This Unity 6 URP project integrates the DigiPhant elephant, MediaPipe tracking,
Savannah course, and editor-only Game view recorder. Open
`Assets/Scenes/SampleScene.unity`.

Setup, restoration, test evidence, controls, and recording instructions are in
`DIGIPHANT_SETUP.md`. Put checked performance videos in the team Drive rather
than this repository, then add the final shared Drive link here.
